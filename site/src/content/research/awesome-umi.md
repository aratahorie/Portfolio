Awesome UMI is a public catalog for exploring and comparing UMI-style tactile and motion data-collection devices, including handheld grippers and hand/arm wearables. It brings together public information from papers, project pages, GitHub repositories, press releases, curated articles, and videos into a structured dataset and a lightweight web interface.

The catalog UI is built with Vite and React and deployed as a static site on GitHub Pages. Device data is bundled at build time from a JSON dataset, allowing users to browse projects, inspect details, filter by axes such as form factor, tactile sensor integration, force/torque sensing, pose tracking, bimanual capability, license, country/region, commercialization stage, and first-publication year.

Awesome UMI also includes a dataset view and a contribution flow for adding missing projects or requesting corrections. The live site provides forms that generate submission JSON, while GitHub issue templates support community review before publication.

Awesome UMI は、UMIスタイルの触覚・モーションデータ収集デバイス（ハンドヘルドグリッパーやハンド/アームウェアラブルを含む）を探索・比較するための公開カタログです。論文、プロジェクトページ、GitHubリポジトリ、プレスリリース、キュレーション記事、動画などの公開情報を集約し、構造化データセットと軽量なWebインターフェースとして提供しています。

カタログのUIはViteとReactで構築され、GitHub Pagesに静的サイトとしてデプロイされています。デバイスデータはJSONデータセットからビルド時にバンドルされ、プロジェクトの閲覧や詳細の確認に加え、フォームファクター、触覚センサー統合、力覚/トルクセンシング、姿勢トラッキング、双腕対応、ライセンス、国・地域、商用化ステージ、初出版年といった軸でのフィルタリングが可能です。

Awesome UMI にはデータセットビューと、未掲載プロジェクトの追加や修正リクエストのためのコントリビューションフローも含まれています。ライブサイトでは投稿用JSONを生成するフォームが提供されており、GitHub Issueテンプレートを通じてコミュニティレビューを経たうえで公開される仕組みになっています。
